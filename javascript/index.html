JavaScript, en bref

JavaScript tourne dans deux mondes : le navigateur (interactivité d'une page, manipulation du DOM) et Node.js (serveur, scripts, outils en ligne de commande — le même langage, sans page web). Toutes les pages qui suivent utilisent Node.js.

Installer Node.js & npm

Prérequis

Installer Node.js (version LTS) installe aussi npm, son gestionnaire de paquets.

npm : dépendances & scripts

node_modules/ ne se versionne pas

Ce dossier se régénère avec npm install à partir de package.json et package-lock.json (celui-ci, à commiter — il fige les versions exactes, comme composer.lock côté PHP).

Modules : import/export vs require

Deux systèmes de modules coexistent. "type": "module" dans package.json active la syntaxe moderne (import/export) ; sans lui, Node utilise l'ancienne (require/module.exports). Les deux font la même chose.

Lequel choisir

ESM pour un projet neuf (c'est la direction de l'écosystème). Les exemples de ce guide utilisent ESM ; la plupart des tutoriels/librairies plus anciens montrent encore du CommonJS — les deux s'utilisent en pratique.
