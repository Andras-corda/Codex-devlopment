C++

Pas un cours complet du langage : ce qu'il faut pour écrire, compiler et lire un programme C++ console — variables, décisions, boucles, et la manipulation de bits (flags, couleurs, textures — le pain quotidien du jeu vidéo).

C++, en bref

C++ est un langage compilé : le code source (texte lisible) doit être traduit en code machine (binaire) par un compilateur avant de pouvoir s'exécuter. Créé par Bjarne Stroustrup en 1979 comme extension du langage C, il donne un contrôle très fin sur la mémoire et les ressources système — ce qui en fait un choix de prédilection pour le développement de jeux vidéo.

Anatomie du premier programme

ÉlémentRôle
#include <iostream>directive préprocesseur — inclut la bibliothèque d'entrée/sortie standard (les bibliothèques standard s'incluent entre chevrons)
int main()point d'entrée du programme ; son type de retour est un entier
int age;déclaration d'une variable — C++ est un langage typé, chaque variable a un type précis
std::espace de noms (namespace) de la bibliothèque standard, suivi de l'opérateur de résolution de portée ::
std::cout <<insère une valeur dans le flux de sortie console (opérateur d'insertion)
std::cin >>extrait une valeur du flux d'entrée console vers une variable
'\n'littéral caractère (guillemets simples) ; \n est une séquence d'échappement pour le retour à la ligne
return 0;code de statut renvoyé par main — 0 signifie que tout s'est bien passé
Instructions & blocs

Chaque instruction se termine par un point-virgule ;. Les accolades { } délimitent un bloc (une nouvelle portée). Les espaces et retours à la ligne sont ignorés par le compilateur — l'indentation n'est là que pour les humains.

Fichier de départ

Un modèle à copier pour chaque nouvel exercice : les trois en-têtes qui servent presque tout le temps en console.

using namespace std : mauvaise pratique ?

Ça dépend d'où. Dans un petit .cpp d'exercice, c'est acceptable : ça évite d'écrire std:: partout. Mais ça importe tous les noms de la bibliothèque standard (count, distance, max…), qui peuvent entrer en conflit avec les tiens. À ne jamais mettre dans un .h : tous les fichiers qui l'incluent en héritent. Dans un vrai projet (et dans Unreal), on écrit std:: explicitement.

Commentaires

Les commentaires ne s'imbriquent pas

Le premier */ rencontré referme le commentaire en cours, même si un /* apparaît entre-temps — inutile d'essayer d'imbriquer des blocs /* */.
