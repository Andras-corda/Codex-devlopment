Variables, types, portée, opérateurs, décisions et boucles — la base de tout programme C++ console.

Variables & constantes

Une variable est un espace de stockage en mémoire ; son type détermine la valeur qu'elle peut contenir. Le qualificateur const rend un identifiant en lecture seule — utile pour protéger une valeur d'un changement accidentel, ou pour donner un nom symbolique à une valeur fixe.

Les variables ne sont PAS initialisées par défaut

Contrairement à d'autres langages, déclarer int c; sans lui donner de valeur laisse un contenu indéterminé (ce qui se trouvait déjà à cet endroit en mémoire). Lire cette variable avant de l'avoir assignée est un bug classique — toujours initialiser à la déclaration par réflexe.

Types à largeur fixe

Pour un contrôle précis de la taille (flags, couleurs, id de texture), C++ propose aussi uint8_t, uint16_t, uint32_t… (bibliothèque <cstdint>) — voir 2 · Manipulation de bits.

Portée (scope)

Les accolades { } délimitent une portée. Une variable déclarée dans une portée interne peut masquer (shadow) une variable de même nom d'une portée externe — l'inverse n'est pas possible.

Pré vs post incrément

a++ (post) utilise la valeur puis incrémente ; ++a (pré) incrémente puis utilise la valeur. int b = a++ + 10; n'est donc pas équivalent à int c = 10 + ++a;. Voir l'ordre de précédence des opérateurs.

Ne jamais comparer des flottants avec ==

0.1 + 0.2 == 0.3 vaut false : la représentation binaire des flottants introduit de minuscules erreurs d'arrondi. Teste plutôt que l'écart est suffisamment petit (std::abs(a - b) < epsilon).

Prise de décision

Un if ne choisit pas forcément une branche d'affichage : il peut aussi modifier l'état du programme.

if vs switch

if pour évaluer des conditions ; switch pour choisir parmi plusieurs valeurs discrètes connues. Le break arrête la comparaison — l'oublier fait « tomber » l'exécution dans le case suivant (fallthrough), parfois volontaire (cases groupés).

enum class crée un ensemble nommé de valeurs commençant à 0 par défaut — plus sûr qu'un simple enum (pas de conversion implicite en entier, les noms restent qualifiés par Item::).

Boucles imbriquées

Une boucle interne s'exécute en entier à chaque itération de la boucle externe — utile pour parcourir une grille 2D (for (y) { for (x) { ... } }).
