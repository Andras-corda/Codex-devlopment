2 · Manipulation de bits

Au lieu de stocker un booléen par drapeau, on peut réserver un bit par drapeau dans une seule valeur — flags de jeu, id de texture, couleur RGBA packée : le pain quotidien du développement bas niveau.

Littéraux binaires & hexadécimaux

Afficher une valeur dans différentes bases

Pourquoi caster en int avant d'afficher

La console traite un uint8_t comme un caractère : l'afficher tel quel montre le caractère ASCII correspondant, pas le nombre. Il faut le convertir (static_cast<int>) pour voir sa valeur numérique. std::bitset<8> (bibliothèque <bitset>) affiche directement une représentation binaire, ce que la console ne sait pas faire nativement.

Tester, activer, inverser un bit (masques)

Un masque se construit en décalant un 1 jusqu'à la position voulue (1 << position), puis en le combinant avec la valeur via l'opérateur adapté.

Désactiver (clear) un bit

AND avec le complément du masque : ~ inverse le masque (un seul 0 à la position voulue, des 1 partout ailleurs), donc le AND ne touche qu'à ce bit et laisse les autres intacts.

Pourquoi 1U et pas 1 ?

1 est un int signé : 1 << 31 touche le bit de signe (comportement indéfini avant C++20). Avec 1U (unsigned), le décalage est bien défini sur toute la largeur d'un uint32_t. Même logique pour ~0U : « tous les bits à 1 » sur un entier non signé.

Empaqueter des données : nibbles

C++ n'a pas de type dédié pour un nibble (4 bits) — on restreint simplement une variable à des valeurs de 0 à 15, puis on empaquette deux nibbles dans un seul octet.
