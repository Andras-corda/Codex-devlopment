1 · Programmation procédurale

Le PHP « de base » : variables, tableaux, fonctions. C'est le style le plus courant pour un script ou une page, et le socle de tout le reste.

L'idée

Un script PHP s'exécute de haut en bas, comme une recette. Les balises <?php … ?> délimitent le code ; en dehors, tout est renvoyé tel quel (utile pour mélanger PHP et HTML, même si ce guide s'en tient au code).

Variables & affectation

Toute variable commence par $. Pas besoin de déclarer son type : PHP le déduit de la valeur, et il peut changer en cours de route (typage dynamique).

Dynamique ≠ imprudent

Rien n'empêche une variable de changer de type — c'est voulu. Pour des paramètres et retours de fonction en revanche, on déclare presque toujours un type (voir Fonctions) : c'est là que strict_types protège vraiment.

Contrairement à C# (types valeur vs référence explicites), PHP a sa propre règle : les tableaux sont copiés à l'affectation (comme un type valeur), les objets sont manipulés par une référence interne (comme un type référence).

gettype / var_dump

var_dump($x) affiche le type ET la valeur — le réflexe numéro un pour déboguer. gettype($x) renvoie juste le type sous forme de texte.

Tableaux

Le tableau (array) est LA structure de données de PHP : liste ordonnée, table associative, pile, file — tout passe par lui.

Piège

array_filter conserve les clés d'origine (des « trous » apparaissent) — utiliser array_values(...) pour ré-indexer si besoin.

Fonctions

Pas de génériques

PHP n'a pas de <T> comme C# ou Java : le typage dynamique en tient lieu (une fonction accepte déjà n'importe quel type tant qu'aucune annotation ne le restreint). Les outils d'analyse statique (PHPStan, Psalm) simulent des génériques via des annotations PHPDoc (@template), mais ce n'est pas une fonctionnalité du langage.

Portée des variables

Différence importante avec C# : en PHP, la portée d'une variable est la fonction, pas le bloc. Une variable déclarée dans un if ou une boucle reste visible après.
