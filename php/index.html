Apprendre à programmer en PHP

Du PHP pur, sans framework (pas de Symfony, pas de Laravel) : juste le langage, son interpréteur, et sa bibliothèque standard.

PHP, en bref

PHP est un langage de script, interprété, à typage dynamique (le type d'une variable se voit à l'exécution) mais de plus en plus typable : déclarations de type sur les paramètres, les retours, les propriétés depuis PHP 7/8. Conçu pour le web, il tourne surtout pour répondre à des requêtes HTTP, mais s'utilise aussi en ligne de commande.

Écrire et exécuter un script

Prérequis

PHP installé (php -v). Aucun framework, aucun gestionnaire de paquets requis pour ce guide — tout tourne avec l'interpréteur seul.

Anatomie d'un script

Le code PHP s'écrit entre <?php et ?> (la balise fermante est même omise en fin de fichier, par convention, pour éviter d'émettre un espace parasite). Il n'y a pas de méthode Main obligatoire : les instructions au niveau racine s'exécutent dans l'ordre.

strict_types

Sans declare(strict_types=1), PHP convertit silencieusement les types incompatibles aux frontières des fonctions ("3" devient 3). Avec, une TypeError est levée à la place. À activer systématiquement dans du code neuf.
