Membres statiques

Héritage

Une classe dérivée est un cas particulier de sa classe de base (mot-clé extends, une seule base possible).

Règles

Une seule classe de base (extends), mais autant d'interfaces que voulu (implements). final class interdit l'héritage ; final sur une méthode interdit sa redéfinition.

Interfaces en détail

Traits — réutiliser du code sans héritage

PHP n'autorise qu'une seule classe de base. Un trait comble ce manque : un bloc de méthodes/propriétés qu'on insère dans plusieurs classes indépendantes, avec use.

Trait, interface, ou héritage ?

Interface = contrat (« quoi »), sans code. Héritage = « est un », relation forte, une seule base. Trait = code partagé horizontalement entre classes sans lien de parenté (« sait faire », avec l'implémentation).
