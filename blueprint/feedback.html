7 · Materials, SFX & VFX

Faire sentir une action sans toucher au gameplay : changer l'apparence d'une surface en jeu, jouer un son, faire apparaître des particules — trois outils indépendants, souvent utilisés ensemble sur un même événement.

Dynamic Material Instance (MID)

Un Material Instance normal a des paramètres fixés une fois pour toutes dans l'éditeur. Une Dynamic Material Instance (MID) est la même chose, mais modifiable pendant le jeu par un Blueprint — dégâts qui s'affichent sur une texture, couleur d'équipe, jauge de recharge sur une arme…

ÉtapeComment
1. Préparer le Materialexposer les valeurs à piloter comme paramètres (clic droit sur un nœud constant → Convert to Parameter) : un Vector pour une couleur, un Scalar pour une valeur (roughness, intensité…)
2. Assignerappliquer le Material (ou un Material Instance classique) au composant (mesh, cube…)
3. Créer le MIDau BeginPlay : Create Dynamic Material Instance, en entrée le Material actuel du composant (Get Material), puis Set Material avec le résultat sur ce même composant
4. ModifierSet Vector Parameter Value / Set Scalar Parameter Value sur la variable MID, avec le nom exact du paramètre
Le nom doit correspondre au caractère près

Parameter Name (dans le nœud Set … Parameter Value) doit être identique au nom du paramètre créé dans le Material — une faute de frappe ne donne aucune erreur visible, le nœud ne fait simplement rien.

Où stocker la MID

Toujours garder une référence à la MID créée dans une variable (Promote to Variable sur la sortie de Create Dynamic Material Instance) : la recréer à chaque appel gaspille de la mémoire et perd les valeurs déjà modifiées.

Attenuation & Concurrency

L'atténuation précise (distance min/max, forme du volume) se règle sur l'asset Sound Attenuation référencé par le son, pas sur le nœud. Un réglage de Concurrency limite le nombre d'instances du même son jouées en même temps (éviter qu'une rafale d'impacts sature l'audio).

Intégrer des VFX

Deux systèmes de particules coexistent dans Unreal : Niagara (actuel) et Cascade (legacy, toujours présent dans d'anciens projets). Les nœuds Blueprint distinguent les deux par leur nom.

BesoinNiagaraCascade (legacy)
Faire apparaître une fois, à un endroitSpawn System at LocationSpawn Emitter at Location
Attacher à un composant (suit ses mouvements)Spawn System AttachedSpawn Emitter Attached
At Location vs Attached — même logique que pour le son

« At Location » fige la position au moment du spawn (une explosion ne suit pas la caisse détruite). « Attached » suit un composant en temps réel (des étincelles sur une épée qui bouge). Même distinction pour Play Sound at Location vs Spawn Sound Attached ci-dessus.
