1 · Programmation procédurale

On décrit comment faire : une séquence d'instructions, des décisions, des répétitions, le tout rangé dans des méthodes réutilisables.

L'idée

Un programme procédural, c'est une recette : les instructions s'exécutent de haut en bas, sauf quand une condition ou une boucle change le chemin.

Variables & affectation

Une variable est un nom qui désigne une valeur en mémoire. En C#, on annonce son type (ou on laisse var le déduire), puis on peut réaffecter.

Piège

Une variable locale non initialisée ne peut pas être lue : int n; Console.WriteLine(n); ne compile pas. C'est une sécurité, pas un défaut.

Constantes (const)

Une constante est une valeur nommée qui ne change jamais. const exige une valeur connue à la compilation (un littéral, ou un calcul de littéraux) : le compilateur remplace chaque usage par la valeur elle-même.

enum : des constantes nommées et regroupées

Quand plusieurs constantes forment un ensemble (des états, des choix possibles), un enum est plus lisible qu'une série de const int.

Tableaux & collections

Méthodes

Une méthode nomme un bloc de code paramétrable. Signature = type de retour + nom + paramètres.

Bonne pratique

Une méthode = une responsabilité, un nom qui dit ce qu'elle fait. Si tu écris « et » dans le nom (ValiderEtEnregistrer), c'est souvent deux méthodes.

Génériques

Un générique est un type ou une méthode paramétré par un type, noté <T>. On écrit le code une seule fois et il fonctionne pour n'importe quel type, sans perdre la vérification à la compilation et sans passer par object.

Méthode générique

Contraintes (where)

Pour appeler des opérations sur T, il faut restreindre ce qu'il peut être.

ContrainteSignifie
where T : classT est un type référence
where T : structT est un type valeur
where T : new()T a un constructeur sans paramètre
where T : IComparable<T>T implémente cette interface
where T : FormeT est Forme ou en hérite

Pourquoi c'est partout

Les collections de la bibliothèque sont génériques : List<T>, Dictionary<TCle, TValeur>, Nullable<T> (qu'on écrit T?). Sans génériques, il faudrait une ListeInt, une ListeString… ou tout stocker en object avec des conversions risquées.

Portée des variables

Règle : une variable existe entre l'accolade { qui la déclare et l'accolade } correspondante. Déclare au plus près de l'usage.

Gestion des erreurs

À éviter

Ne pas « avaler » une exception avec un catch vide : l'erreur disparaît sans trace. Attrape seulement ce que tu sais traiter.
