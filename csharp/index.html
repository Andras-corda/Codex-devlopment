Apprendre à programmer en C#

Un guide condensé et illustré. Trois pages, trois styles de programmation : procédural, orienté objet, asynchrone.

C# et .NET

C# est un langage typé statiquement, compilé, généraliste. .NET est la plateforme qui l'exécute : compilateur, machine virtuelle (le runtime), et une immense bibliothèque standard.

Les 3 paradigmes couverts

Un même problème peut s'écrire de plusieurs façons. Ces styles se combinent : un vrai programme est souvent orienté objet et asynchrone, avec des blocs procéduraux à l'intérieur des méthodes.

StyleIdée centraleOn s'en sert pour…Page
ProcéduralUne suite d'instructions, découpée en méthodesLogique de calcul, algorithmes, scripts1 · Procédural
Orienté objetDes objets qui réunissent données + comportementsModéliser un domaine, structurer une grosse appli2 · Orienté objet
AsynchroneAttendre (réseau, disque) sans bloquer le threadAppels web, I/O fichier, bases de données, UI fluide3 · Asynchrone

En complément, une page de référence rassemble les types de données, les collections et la rédaction d'UML.

Créer un projet

Prérequis

Le SDK .NET installé et un éditeur (Visual Studio, VS Code + C# Dev Kit, ou Rider). Vérification : dotnet --version.

Contenu du dossier :

FichierRôle
Program.csPoint d'entrée — le code qui s'exécute au lancement
MonApp.csprojConfig du projet : version de .NET, dépendances (NuGet), options
bin/, obj/Fichiers compilés (générés, à ne pas versionner)

Anatomie d'un programme

Depuis .NET 6, un programme minimal tient en une ligne grâce aux top-level statements : le compilateur génère la méthode Main pour vous.

À retenir

using = « rendre accessibles les types de cet espace de noms ». Console vit dans System. Les using courants sont implicites dans les projets récents (ImplicitUsings).

Aide-mémoire CLI

Comment suivre le guide

  1. Crée un projet console vide et garde un terminal ouvert sur dotnet run.
  2. Lis les pages dans l'ordre : chaque page suppose la précédente acquise.
  3. Recopie chaque exemple (bouton Copier), exécute-le, puis modifie une valeur pour voir l'effet.
